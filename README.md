
# Quiz App - CLI

A command-line quiz application built using Python.

## Features
- Contains 5 multiple-choice questions.
- Displays four options for each question.
- Takes answers from the user.
- Checks answers and displays correct or wrong.
- Keeps track of the score.
- Calculates the final percentage.
- Handles invalid user inputs.

## Concepts Used
- Lists
- Dictionaries
- Functions
- For loops
- While loops
- If-Else conditions
- User input
- F-strings
- len() function

## How to Run

python quiz_app.py
